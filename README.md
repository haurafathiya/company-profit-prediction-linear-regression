# 📈 Startup Profit Prediction using Multiple Linear Regression

Predicting company profit based on R&D, Administration, and Marketing expenditure using Multiple Linear Regression.

---

## 📌 Project Overview

This project applies the CRISP-DM workflow to build a machine learning regression model for predicting company profit.

The analysis includes:

- Data Understanding
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Multiple Linear Regression
- Model Evaluation

---

## 📂 Dataset

- 1,000 company records
- Features:
  - R&D Spend
  - Administration
  - Marketing Spend
- Target:
  - Profit

---

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Model

Algorithm:

- Multiple Linear Regression

Training/Test Split:

- 80% Training
- 20% Testing

---

## 📈 Model Performance

| Metric | Value |
|---------|-------|
| R² Score | **0.9828** |

The model demonstrates excellent predictive performance, indicating that R&D expenditure is the strongest predictor of company profit.

## 💡 Key Insights

- R&D Spend has the strongest positive relationship with profit.
- Marketing Spend also contributes positively.
- Administration expenditure shows a weaker relationship.
- Multiple Linear Regression achieved very high predictive accuracy (R² = 0.9828).
